# SimpleGrid: The next 250

A standalone interactive ABM and events proposal for Mukund, prepared by Tanmay Garg.

## Open

Double-click `index.html`. No build step, ChatGPT account, backend or API key is required. Keep the CSS, JavaScript and assets alongside the HTML.

For a local server, run `python -m http.server 8080` in this folder and open `http://localhost:8080`.

## Publish

Upload this folder to any static web host. For GitHub Pages, select the branch and root directory in the repository's Pages settings. Choose the repository visibility and site access deliberately: this is a personalised proposal containing planning budgets.

## Files

- `index.html`: page structure and strategy
- `style.css`, `playful.css`: responsive layout and animation
- `app.js`, `playful.js`: calculator, filters, dialogs and original SVG illustrations
- `assets/logo.png`: supplied SimpleGrid logo
- `assets/fonts/`: locally bundled fonts

Animations respect reduced-motion settings and can be switched off. No analytics, data collection, autoplay audio or external embeds are included. Numbers are planning assumptions, not forecasts. Mockups are illustrative concepts.
